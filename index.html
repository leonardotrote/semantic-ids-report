Filtrar por tokens

Um código por nível, do geral ao específico.

Como ler um grupo
  • Coesão: cosseno médio entre os filmes do grupo. Maior que a do grupo pai = o token juntou filmes parecidos.
  • Palavras: mais frequentes no grupo que no catálogo; o número é a contagem no grupo.
  • Gêneros: fração do grupo; "×" compara com o catálogo.

Buscar filme

    Como ler os vizinhos
    • Vizinhos: os mais parecidos no embedding original. Tokens preenchidos = compartilhados com o filme.
    • O token tracejado só desempata colisões.
